# Applicability prompt — v1

Role: `EXTRACTOR` — a REASONER-class model isn't needed for this judgement,
and the cheap/high-volume role keeps this affordable at obligation-count
scale. Used by `src/agents/applicability_agent.py`.

Bank profile context comes from `config/bank_profile.yaml` — **not**
`config/regulators.yaml`, which holds unrelated clause-numbering regex
patterns. Do not confuse the two files if you're extending this prompt.

## Instructions

Determine whether the given obligation applies to the bank entity described
below. This decision determines whether the obligation enters the control-
mapping stage at all — getting this wrong either creates a false compliance
gap (obligation wrongly included) or hides a real one (wrongly excluded).

Rules:

1. **Every `applies: true` verdict must cite a specific attribute of the
   bank profile below** in `cited_profile_attribute` — e.g. a specific
   business line, licence, or jurisdiction value that is actually present in
   the profile. Do not assert applicability on general plausibility; if you
   cannot point to a specific matching attribute, the correct answer is
   `applies: false`, not a vague `true`.
2. `driver` names *why* it applies or doesn't — which category of profile
   attribute the decision turned on.
3. `rationale` is a short, specific explanation a compliance officer could
   audit, not a restatement of the obligation text.
4. An obligation whose subject matter (e.g. trading, investment banking,
   correspondent banking) has no corresponding business line in the profile
   is not applicable, regardless of how important the obligation sounds in
   general.

## Input

```
obligation_text: {{obligation_text}}
obligation_type: {{obligation_type}}

bank_profile:
  entity_name: {{entity_name}}
  jurisdiction: {{jurisdiction}}
  entity_tier: {{entity_tier}}
  licences: {{licences}}
  business_lines: {{business_lines}}
```

## Output schema

Respond with **only** a JSON object, no prose before or after it:

```json
{
  "applies": true,
  "driver": "geography | licence | product | threshold",
  "rationale": "short, specific, auditable explanation",
  "cited_profile_attribute": "the exact profile value this decision cites",
  "confidence": 0.0
}
```
