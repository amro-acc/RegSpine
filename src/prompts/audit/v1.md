# Audit prompt — v1

Role: `REASONER` (`gpt-5.1` primary, `gpt-5.6-luna` fallback). Used by
`src/agents/audit_agent.py`.

**Important — read before answering**: `gap_class` is a closed-taxonomy
field. When the obligation-control mapping's `coverage_level` given below is
`none` or `partial`, the calling code overrides whatever `gap_class` you
return with a deterministic value (`no_control` / `partial_coverage`) — gap
*existence and class* are computed in code wherever the data allows it, not
freely decided by a model. Your judgement is
still what's used for `has_gap` (only relevant when coverage_level is
`full`), `narrative`, and the five `risk_factors`.

## Instructions

1. If `coverage_level` is `full`: decide whether there is nonetheless a real
   deficiency (`has_gap`) — e.g. the control's automation/frequency doesn't
   match what the obligation actually requires, or its description implies
   a design weakness. If you see no deficiency, set `has_gap: false` and
   leave the other fields as directed below — **do not invent a gap to
   have something to report.**
2. `gap_class`, when relevant, must be one of exactly: `no_control`,
   `partial_coverage`, `control_no_evidence`, `evidence_stale`,
   `control_ineffective`, `ownership_unclear`, `jurisdictional_mismatch`,
   `contradictory_requirement`. Do not invent a new class name.
3. `risk_factors`: five integers, 1-5 each, with your rationale for each
   folded into `narrative` — **do not compute or state a final risk score
   or band yourself.** That arithmetic happens in code
   (`src/risk/scoring.py`) from these factors; a model-stated final number
   is discarded, not read.
4. `narrative` must be specific enough for a compliance officer to act on —
   name what's missing or weak, not a restatement of the obligation.

## Input

```
obligation_text: {{obligation_text}}
obligation_type: {{obligation_type}}

control_title: {{control_title}}
control_design_description: {{control_design_description}}
control_type: {{control_type}}
control_automation: {{control_automation}}
control_frequency: {{control_frequency}}

coverage_level: {{coverage_level}}
mapping_rationale: {{mapping_rationale}}
```

## Output schema

Respond with **only** a JSON object, no prose before or after it:

```json
{
  "has_gap": true,
  "gap_class": "one of the eight closed values above, or null if has_gap is false",
  "narrative": "specific, actionable finding",
  "risk_factors": {
    "regulatory_severity": 3,
    "enforcement_likelihood": 3,
    "business_exposure": 3,
    "control_weakness": 3,
    "remediation_urgency": 3
  }
}
```
