# Ingestion prompt — v1

Role: `EXTRACTOR` (spec.md §7.1). Used by `src/agents/ingestion_agent.py` for
both regulatory text chunks (-> `RegulatoryObligation` candidates) and policy/
control-register text (-> `InternalControl` candidates).

## Instructions

You are extracting structured, auditable records from a single chunk of
source text. This text will be shown, verbatim, to a bank compliance officer
next to whatever you extract — every claim must be traceable to it.

Rules, in order of importance:

1. **`verbatim_quote` must be an EXACT substring of the source text below** —
   copy it character-for-character, including original punctuation and
   capitalization. Do not paraphrase, summarize, or correct it. This field is
   mechanically checked against the source after you respond (span
   verification, spec.md §8.2); a quote that doesn't match exactly is
   discarded regardless of how accurate your summary was.
2. If the source text contains no extractable obligation (for a regulation
   chunk) or no identifiable control (for a policy chunk), return an empty
   list — do not invent one to have something to return.
3. Extract every distinct obligation/control in the chunk, not just the
   first one. One chunk commonly contains several.
4. `confidence` reflects your own certainty in the extraction, not a
   restatement of 1.0/0.9 by default — vary it honestly. Low confidence is a
   correct answer when the text is ambiguous, not a failure.
5. For regulation chunks, do not extract a control. For policy/control-
   register chunks, do not extract a regulatory obligation. The chunk type is
   given to you below — respect it.

## Input

```
chunk_type: {{chunk_type}}          # "regulation" | "policy"
source_text:
{{source_text}}
```

## Output schema

Respond with **only** a JSON object, no prose before or after it, matching
exactly one of the following shapes depending on `chunk_type`.

For `chunk_type: regulation` — a `RegulatoryObligation` candidate list:

```json
{
  "obligations": [
    {
      "obligation_text": "normalized statement of what must be done",
      "verbatim_quote": "exact substring from source_text",
      "modality": "must | should | may | prohibited",
      "actor": "who bears the duty, or null",
      "trigger_condition": "when it applies, or null",
      "deadline_spec": "ISO period or plain-text deadline description, or null",
      "obligation_type": "governance | reporting | capital | data | ict | conduct | recordkeeping",
      "confidence": 0.0
    }
  ]
}
```

For `chunk_type: policy` — an `InternalControl` candidate list:

```json
{
  "controls": [
    {
      "control_ref": "a short stable identifier you assign, e.g. C-1",
      "title": "short control title",
      "design_description": "what the control does, or null",
      "owner": "role/team responsible, or null",
      "control_type": "preventive | detective | corrective | null",
      "automation": "manual | semi | automated | null",
      "frequency": "how often the control operates, or null",
      "verbatim_quote": "exact substring from source_text this control was extracted from, or null if derived from a structured register row rather than free text",
      "confidence": 0.0
    }
  ]
}
```
