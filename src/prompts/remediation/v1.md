# Remediation prompt — v1

Role: `EXTRACTOR` (GPT-5.1) — same reasoning as `mapping_agent.py`: this is a
drafting task at gap-count volume, not a low-volume high-judgement one.
Used by `src/agents/remediation_agent.py`.

## Instructions

You are drafting a remediation recommendation for a ratified compliance
gap. This becomes an auditor-consumable artifact — a compliance officer
will assign it to someone, not just read it.

Rules:

1. `action_type` must be exactly one of: `POLICY_UPDATE`, `NEW_CONTROL`,
   `CONTROL_ENHANCEMENT`, `PROCESS_CHANGE`, `TRAINING`, `OTHER`. Pick the one
   that best matches what actually needs to happen — `NEW_CONTROL` for a
   `no_control` gap, `CONTROL_ENHANCEMENT` for a `partial_coverage` or
   `control_ineffective` gap with an existing control to build on, etc.
2. `action` must be concrete and assignable — "improve monitoring" is not
   acceptable, "add automated daily reconciliation checks comparing X
   against Y" is.
3. `monitoring_metric` must be a **specific, measurable** metric that could
   actually be tracked on an ongoing basis — e.g. "percentage of incidents
   reported within the 24-hour window," not "monitor compliance."
4. `effort_estimate` is a rough, honest size (e.g. "2-3 sprint days," "1
   quarter") — do not default to a fixed value regardless of scope.
5. Base the recommendation on the gap's actual `narrative` and `gap_class`,
   not a generic template answer.

## Input

```
obligation_text: {{obligation_text}}
control_title: {{control_title}}

gap_class: {{gap_class}}
narrative: {{narrative}}
severity: {{severity}}
```

## Output schema

Respond with **only** a JSON object, no prose before or after it:

```json
{
  "action_type": "POLICY_UPDATE | NEW_CONTROL | CONTROL_ENHANCEMENT | PROCESS_CHANGE | TRAINING | OTHER",
  "action": "concrete, assignable description of what to do",
  "control_design_delta": "specifically what changes about the control's design, or null",
  "owner_role": "role/team who should own this",
  "effort_estimate": "honest, scoped-to-this-gap estimate",
  "test_plan": "how to verify the remediation actually closed the gap",
  "monitoring_metric": "specific, measurable ongoing-monitoring metric",
  "confidence": 0.0
}
```
